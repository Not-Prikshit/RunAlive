--------------------------------------------------------------------------------
PART 1: DATABASE OPTIONS (WHAT YOU NEED TO PROVIDE)
--------------------------------------------------------------------------------

The RunAlive backend uses PostgreSQL with the PostGIS spatial extension for boundary
math (ST_DWithin) and geolocation indexing.

Choose ONE of the two options below:

OPTION A — LOCAL DOCKER (Recommended if you already use Docker):
  1. Open Docker Desktop on Windows.
  2. Open a terminal (PowerShell or Command Prompt) in C:\RunAlive.
  3. Start the Postgres PostGIS container:
       docker compose up -d
  4. Run the database migrations and demo seed:
       pnpm --filter @runalive/server db:migrate
       pnpm --filter @runalive/server db:seed
  5. The database is now ready on localhost:5432!

OPTION B — FREE CLOUD DATABASE (Supabase or Neon.tech — No Docker needed):
  1. Go to https://supabase.com or https://neon.tech and create a free PostgreSQL DB.
  2. In the SQL Editor of your provider, enable PostGIS by running:
       CREATE EXTENSION IF NOT EXISTS postgis;
  3. Open C:\RunAlive\apps\server\.env and update DATABASE_URL:
       DATABASE_URL="postgresql://postgres:[YOUR-PASSWORD]@[YOUR-HOST]:5432/postgres?sslmode=require"
  4. In C:\RunAlive, run migrations:
       pnpm --filter @runalive/server db:migrate
       pnpm --filter @runalive/server db:seed

NOTE ON OFFLINE / INSTANT DEMO MODE:
  The server and web frontend now include a resilient fallback mode! If you haven't 
  set up Docker or a database yet, you can still immediately launch the web app 
  and test the UI, lobby, match controls, and danger meter without crashing.

--------------------------------------------------------------------------------
PART 2: RUNNING THE APPLICATION
--------------------------------------------------------------------------------

Open TWO terminal windows in `C:\RunAlive`:

TERMINAL 1 (Backend Server):
  Run:
    pnpm dev:server

  Expected output:
    🚀 RunAlive server listening on port 3000

TERMINAL 2 (Web App Frontend):
  Run:
    pnpm dev:web

  Expected output:
    VITE v5.4.21 ready in ... ms
    ➜ Local: http://localhost:5173/

--------------------------------------------------------------------------------
PART 3: HOW TO PLAY & TEST IN THE BROWSER
--------------------------------------------------------------------------------

1. Open your browser and navigate to:
     http://localhost:5173

2. Sign In:
   - Click one of the Instant Demo Sign-in buttons:
       👑 Host    (host@demo.runalive.app)
       🏃 Runner  (runner@demo.runalive.app)
       🎯 Seeker  (seeker@demo.runalive.app)
   - Or create a new account using the Sign Up form.

3. Grant Geolocation Permission:
   - When prompted by your browser, click "Allow" for Location access.
   - This places your blue marker onto the campus map and feeds GPS to the Danger Meter.

4. Host a Game:
   - Click "Customize Perimeter on Map" or "Quick Host".
   - In the Zone Editor, adjust the radius slider (e.g., 500m) and click "Confirm Perimeter & Host Match".
   - A 6-character room code (e.g., XK92WP) will appear at the top.

5. Join as a Runner or Seeker (Multiplayer Testing):
   - Open an Incognito window or second browser tab at http://localhost:5173.
   - Sign in as "Runner" or "Seeker".
   - Enter the 6-character code in "Join Match" and click "Enter Match".
   - As Runner: Observe your real-time Danger Meter bar (Safe, Low, Med, High, Critical).
   - As Seeker: Look for runner location blips on the map and use the "REPORT CATCH" button.
   - As Host: Use the Pause, Resume, or Exit buttons in the top HUD.

6. Match History:
   - From the lobby, click "Match History" to view past match summaries, winners, and play times.

--------------------------------------------------------------------------------
PART 4: MOBILE APP TESTING (REACT NATIVE / EXPO) — OPTIONAL
--------------------------------------------------------------------------------

If you want to run the native Android / iOS app on a physical phone:
1. Install Expo Go on your mobile phone from Google Play Store or Apple App Store.
2. Open a terminal in C:\RunAlive and run:
     pnpm --filter @runalive/mobile start
3. Scan the QR code shown in the terminal with your phone camera or Expo Go.
4. Ensure your phone is on the same local Wi-Fi network as your PC, and update
   EXPO_PUBLIC_API_URL in `apps/mobile/.env` to your PC's local IP (e.g. http://192.168.1.50:3000).
